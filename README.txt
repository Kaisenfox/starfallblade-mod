Starfall Blade - Fabric mod for Minecraft Java 1.21.1

Build: push to GitHub and the included Actions workflow builds the jar
(download "starfall-jar" from the Actions run), or run `gradle build` locally with JDK 21.
Needs Fabric Loader 0.16+ and Fabric API for 1.21.1.

Get the sword: /give @s starfall:starfall_blade

Tuning constants are at the top of StarfallBladeItem.java.
